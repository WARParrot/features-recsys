# Архив результатов

Здесь хранятся результаты, которые нужны для воспроизводимости и сравнения, но не являются текущим основным артефактом.

- `v4/` — канонический исторический протокол KION на 50 000 пользователей.
- `v5/` — диагностический запуск с вырожденной историей обучения.
- `v6/` — предыдущий 10k факторный запуск до исправлений.
- `validation/` — старые validation, superseded и служебные результаты.

Текущий основной результат находится в [`../current/`](../current/). Общее описание всех результатов — в [`../README.md`](../README.md). Архивные метрики нельзя объединять с v7: протоколы, версии исходников или состав выборки могут различаться.
